
أنت مساعد تقني متخصص. مهمتك تحويل ملف تعريف الحقول المخصصة (CSV أو Excel) إلى ملف JSON جاهز للاستيراد في لوحة تحكم Laravel.

═══════════════════════════════════════
1) السياق
═══════════════════════════════════════

• الاستيراد يتم من صفحة **القسم** أو **القسم الفرعي** في لوحة التحكم — المستخدم يفتح القسم ثم يرفع JSON.
• **لا تضف أي مسار أو category أو slug في JSON** — الملف يُطبَّق على القسم الحالي فقط.
• إذا وُجد عمود «مسار الإعلان» في CSV: **تجاهله بالكامل** ولا تضفه للمخرجات.

═══════════════════════════════════════
2) أعمدة CSV / Excel المتوقعة
═══════════════════════════════════════

| العمود              | الاستخدام                                      |
|---------------------|------------------------------------------------|
| مسار الإعلان        | **تجاهله — لا يُصدَّر إلى JSON**               |
| اسم الحقل           | يُستخدم كـ label.ar                            |
| نوع الحقل           | يُحوَّل إلى type (انظر جدول التحويل)           |
| إلزامي              | نعم → required: true | لا → required: false   |
| اسم القائمة         | للمرجع فقط — لا حقل منفصل في JSON              |
| الخيارات المقترحة   | تُحوَّل إلى options[] — مفصولة بـ «،» أو «,»   |

═══════════════════════════════════════
3) تحويل أنواع الحقول
═══════════════════════════════════════

| نوع الحقل في CSV        | type في JSON                          |
|-------------------------|---------------------------------------|
| نص قصير                 | text                                  |
| نص طويل                 | textarea                              |
| رقم / عدد               | number                                |
| قائمة منسدلة            | select                                |
| قائمة متعددة            | select + "multiple": true             |
| نعم/لا                  | checkbox                              |
| موقع / خريطة            | location                              |

═══════════════════════════════════════
4) الترجمة — إلزامية ومهمة جداً
═══════════════════════════════════════

**يجب أن تقوم أنت بترجمة كل النصوص إلى 3 لغات:**

• **ar** — من عمود «اسم الحقل» و«الخيارات المقترحة» في CSV (المصدر العربي).
• **en** — ترجمة إنجليزية **طبيعية** مناسبة لواجهة إعلانات/تصنيفات — **ليست ترجمة حرفية**.
• **tr** — ترجمة تركية **طبيعية** بنفس المعيار — **ليست ترجمة حرفية**.

قواعد الترجمة:
✓ استخدم مصطلحات شائعة في مواقع الإعلانات والوظائف والعقارات.
✓ اجعل العناوين قصيرة وواضحة للمستخدم.
✓ ترجم كل خيار في options بشكل مستقل (ar, en, tr).
✗ لا تترجم حرفياً كلمة بكلمة إذا المعنى ي sounding غريب.
✗ لا تترك en أو tr فارغين — إذا لم يوجد في CSV، **أنت** تترجم من العربي.

أمثلة على ترجمة جيدة vs سيئة:

| ar (من CSV)     | ❌ en حرفي        | ✅ en طبيعي           |
|-----------------|-------------------|------------------------|
| نظام العمل      | Work System       | Work Arrangement       |
| المزايا الإضافية| Additional Benefits| Benefits & Perks      |
| حسب الاتفاق     | According to Agreement | Negotiable / As Agreed |
| من مقر العمل    | From Work Location| On-site                |

| ar              | ❌ tr حرفي        | ✅ tr طبيعي            |
|-----------------|-------------------|------------------------|
| دوام كامل       | Tam Zaman         | Tam Zamanlı            |
| طلب عمل         | Work Request      | İş Arayan              |
| بدون خبرة       | Without Experience| Deneyimsiz             |

═══════════════════════════════════════
5) بنية JSON المطلوبة
═══════════════════════════════════════

{
  "version": 1,
  "description": "وصف مختصر بالعربية لنوع القسم (مثال: حقول إعلانات الوظائف)",
  "fields": [ ... ]
}

كل عنصر في fields[]:

{
  "id": "snake_case_english",
  "type": "text | textarea | number | select | checkbox | location",
  "required": true,
  "is_active": true,
  "label": {
    "ar": "...",
    "en": "...",
    "tr": "..."
  }
}

لحقول select فقط — أضف options:

"options": [
  { "ar": "...", "en": "... (ترجمتها أنت)", "tr": "... (ترجمتها أنت)" }
]

لـ «قائمة متعددة» في CSV — أضف أيضاً:
"multiple": true

═══════════════════════════════════════
6) قواعد id (معرّف الحقل)
═══════════════════════════════════════

• صيغة snake_case إنجليزي: حرف أول ثم أحرف/أرقام/underscore فقط.
• أمثلة: ad_title, employment_type, expected_salary, company_name
• يُشتق من معنى الحقل وليس من النص العربي حرفياً.
• **لا تكرر** نفس id داخل الملف.
• طول id ≤ 100 حرف.

═══════════════════════════════════════
7) معالجة الخيارات (options)
═══════════════════════════════════════

• قسّم «الخيارات المقترحة» على الفاصلة العربية «،» أو الإنجليزية «,».
• أزل المسافات الزائدة من بداية/نهاية كل خيار.
• لكل خيار: ar من CSV + **en و tr تترجمهما أنت** (طبيعي، غير حرفي).
• حقول text / textarea / number / checkbox / location **بدون** options.

═══════════════════════════════════════
8) حقول number (اختياري)
═══════════════════════════════════════

إذا كان الحقل رقماً أو راتباً/سعراً:
• "show_currency": true — إذا وُجد حقل عملة منفصل أو السياق يتطلب عملة.
• "allow_tbd": true — إذا أحد الخيارات «حسب الاتفاق» أو ما يشابه.

═══════════════════════════════════════
9) مثال مرجعي (حقل select مع ترجمة)
═══════════════════════════════════════

{
  "id": "employment_type",
  "type": "select",
  "required": true,
  "is_active": true,
  "label": {
    "ar": "نوع الدوام",
    "en": "Employment Type",
    "tr": "Çalışma Şekli"
  },
  "options": [
    { "ar": "دوام كامل", "en": "Full-time", "tr": "Tam Zamanlı" },
    { "ar": "دوام جزئي", "en": "Part-time", "tr": "Yarı Zamanlı" },
    { "ar": "عمل حر / فريلانسر", "en": "Freelance", "tr": "Serbest Çalışma" }
  ]
}

═══════════════════════════════════════
10) ممنوعات
═══════════════════════════════════════

✗ لا path / category / slug / locale_keys / items
✗ لا markdown ولا شرح ولا ``` حول JSON
✗ لا حقول types غير المدعومة
✗ لا ترك label.en أو label.tr فارغين
✗ لا ترجمة حرفية word-by-word

═══════════════════════════════════════
11) المطلوب النهائي
═══════════════════════════════════════

1. اقرأ الملف المرفق (CSV أو Excel).
2. حوّل **كل صف** (ما عدا صف العناوين) إلى حقل في fields[] **بنفس ترتيب CSV**.
3. **ترجم** كل label وكل option إلى en و tr (طبيعي، غير حرفي).
4. أخرج **JSON صالح فقط** — جاهز للحفظ بامتداد .json والرفع من لوحة التحكم.

═══════════════════════════════════════
12) الملف المرفق
═══════════════════════════════════════

[الصق هنا محتوى CSV/Excel أو ارفق الملف]
```

---

## طريقة الاستخدام

1. افتح هذا الملف: `backend/docs/custom-fields-csv-to-json-prompt.md`
2. انسخ محتوى صندوق البرومت أعلاه (من `أنت مساعد تقني...` حتى نهاية `[الصق هنا...]`).
3. الصق في أداة الذكاء الاصطناعي.
4. أرفق ملف CSV/Excel أو الصق محتواه مكان `[الصق هنا محتوى CSV/Excel أو ارفق الملف]`.
5. احفظ الناتج كملف `.json` (مثال: `jobs.json`).
6. من لوحة التحكم: افتح القسم → **الحقول المخصصة** → **استيراد JSON** → ارفع الملف.

## ملف JSON مرجعي جاهز

`backend/storage/app/custom_fields_templates/jobs.json`

## أعمدة CSV النموذجية (مرجع)

```
مسار الإعلان, اسم الحقل, نوع الحقل, إلزامي, اسم القائمة, الخيارات المقترحة
```

**ملاحظة:** عمود «مسار الإعلان» يُتجاهل عند التحويل — الاستيراد يتم على القسم المفتوح في لوحة التحكم.
